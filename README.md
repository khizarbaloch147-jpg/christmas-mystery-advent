# The Case of the Missing Christmas Star

A 24-day Christmas mystery that plays in a browser, with the internet off. The download is one HTML file. There is nothing to install and no account to make.

## For the buyer

1. Unzip the folder.
2. Double-click `index.html`.
3. Pick a mode.
   - **Advent** opens door 1 on 1 December, door 2 on 2 December, and so on. After 24 December every door is open. Before December the doors stay shut.
   - **Binge** opens the next door as soon as the current puzzle is solved, on any date. Use this to play the whole case in one sitting, or if you start after Christmas.
4. Read the scene, solve the puzzle, and keep the clues in the notebook.
5. On door 24, name who took the star, why, and where it is hidden.

Progress stays in that browser. Settings has a sound switch and a reset. Reset asks before it clears the case.

Christmas in the story is 2026. That year is part of one puzzle, and it is printed on every screen.

The file is for the person who bought it, to play on their own laptop, tablet, or phone.
